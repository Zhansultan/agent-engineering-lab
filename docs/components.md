## Описание компонентов

### 1. Context Builder

**Назначение**: Собирает контекст для запроса к модели.

**Входы**:
- Сообщение пользователя
- История диалога (messages)
- Определения инструментов (tools)
- System prompt (опционально)

**Выходы**:
- JSON-объект запроса для Ollama API

**Границы**:
- НЕ выполняет HTTP-запросы
- НЕ знает о конкретной модели
- НЕ хранит состояние между вызовами

---

### 2. HTTP Client

**Назначение**: Отправляет запросы к Ollama API.

**Входы**:
- JSON-запрос от Context Builder
- URL endpoint (`http://localhost:11434/api/chat`)

**Выходы**:
- JSON-ответ от Ollama
- Ошибки сети/таймаута

**Границы**:
- НЕ разбирает содержимое ответа
- НЕ принимает решений о tool calling
- Только транспорт

---

### 3. Parser

**Назначение**: Разбирает ответ модели.

**Входы**:
- JSON-ответ от Ollama

**Выходы**:
- Текстовый ответ (если модель ответила)
- Tool calls (если модель запросила инструмент)
- Ошибки парсинга

**Границы**:
- НЕ выполняет tool calls
- НЕ валидирует аргументы инструментов
- Только извлечение данных

---

### 4. Executor

**Назначение**: Выполняет вызовы инструментов.

**Входы**:
- Tool call от Parser: `{function: {name, arguments}}`

**Выходы**:
- Результат выполнения: `{role: "tool", content: ...}`
- Ошибки (как результат, не исключение)

**Границы**:
- Работает ТОЛЬКО с sandbox
- НЕ выходит за пределы разрешённой папки
- НЕ выполняет запись/удаление
- НЕ запускает произвольные команды

**Реализация**: `renderer/lab/tool.mjs`

---

### 5. Sandbox

**Назначение**: Изолированная файловая система для инструментов.

**Расположение**: `renderer/lab/sandbox/`

**Ограничения**:
- Только чтение
- Максимум 8 КиБ на файл
- Максимум 20 результатов поиска
- Проверка symlinks (realpath)

**Границы**:
- НЕ доступна модели напрямую
- Доступ только через Executor
- Путь проверяется перед каждой операцией

---

## Доступные инструменты

| Имя | Действие | Аргументы |
|-----|----------|-----------|
| `list_directory` | Список файлов в папке | `path: string` |
| `read_text` | Чтение текстового файла | `path: string` |
| `find_files` | Поиск файлов по имени | `pattern: string` |
| `search_text` | Поиск текста в файлах | `query: string` |

## Правила работы

1. **Один tool call за раз**: Executor обрабатывает один вызов
2. **Ошибки как данные**: Ошибка возвращается модели, не выбрасывается
3. **Явные границы**: Каждый компонент делает одну вещь
4. **Stateless**: Компоненты не хранят состояние между вызовами
